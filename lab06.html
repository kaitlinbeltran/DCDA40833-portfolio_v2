Lab 6: Interactive Hometown Map

Lab Requirements

This lab required creating an interactive hometown map that combined custom basemap design with web mapping. The project involved designing a basemap in Mapbox Studio, preparing location data in CSV format, and using Python tools to generate an interactive map for the web. The goal was to connect design, technical implementation, and personal storytelling through a map-based project.

Description: What I Built

For this lab, I created an interactive hometown map highlighting meaningful locations from Manhattan Beach and Hermosa Beach, California. The project combines a custom-designed Mapbox basemap with Python-generated web mapping. The final map includes categorized markers, pop-up descriptions, and images representing places that are personally important to me.

The map was generated using Python libraries including Folium and Pandas, which allowed me to process location data from a CSV file and create an interactive map displayed within my portfolio website.

Design Inspiration

My basemap design was inspired by my favorite show, Breaking Bad. I had just finished watching the series and thought it would be fun to incorporate its visual style into my map design. Specifically, I used the show’s introductory title sequence as my main inspiration, as those are the colors typically associated with the series.

As displayed in the images below, the introduction features a dark background contrasted with bright chemical-green smoky visual elements. I translated this color scheme into my basemap by using a dark charcoal color for the land and deep green tones for the water and roads. The bright green roads reflected the chemical-green color that appears in the smoky background of the show’s introduction.

I also kept the map relatively minimal, with the goal of mirroring the clean and high-contrast look of Breaking Bad. Overall, my goal was to capture the show’s recognizable, contrasting palette into my map by using darker tones and distinct greens while being simplistic.

Cartographic Challenges

One of the main challenges I faced while designing the basemap was deciding how different features should appear at different zoom levels. I had to pause and think about which map elements should be visible when zoomed out versus when zoomed in.

I aimed to avoid having too many labels or features at smaller scales because I didn’t want the map to look cluttered. I had to create a hierarchy in my head of which elements were important at which zoom levels.

Since I don’t typically consider myself very design-oriented, a lot of this process was new and exploratory for me. I experimented with label density, road visibility, and other elements until the map felt balanced, readable, and visually effective overall.

Technical Challenges

The most difficult part of the project for me was understanding how to initially generate the interactive map using Python. At first, I struggled to troubleshoot errors and figure out how the different files all worked together.

However, I overcame this with the help of the AI chatbot to explain any error messages that came along. This tool helped me identify and understand issues that were easy to fix but difficult to detect.

For example, I referenced the CSV file name without including the folder path, which caused errors in my script. Later, I did the same thing with the HTML file. Because AI had previously identified and explained this issue, I was able to recognize the mistake quickly and avoid repeating it.

I appreciated the chatbot’s ability to not only identify problems but also explain how to fix them, which helped strengthen my coding abilities and overall understanding of how the files and scripts interacted.

What This Lab Demonstrates About My Abilities

This lab demonstrates my ability to combine design inspiration, personal storytelling, and technical mapping tools into one project. I used Mapbox Studio to build a custom basemap, organized location data in CSV format, and used Python libraries such as Folium and Pandas to generate an interactive web map.

It also reflects my ability to work through unfamiliar technical challenges and connect creative vision with implementation. Rather than simply making a functional map, I made intentional design choices about color, hierarchy, and visual style while also troubleshooting the code and file structure needed to publish the final project.

Key Takeaways

One key takeaway from this lab is that effective digital mapping requires both design thinking and technical problem-solving. Building the map was not just about plotting locations, but also about making deliberate choices about visual hierarchy, usability, and storytelling. This project reinforced how creative direction and technical execution have to work together in digital projects.
